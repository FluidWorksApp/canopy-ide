Canopy 0.5.14 adds a local fast model, a floating phone preview and fixes dialogs that ran off the screen.

### Local fast model
- Canopy downloads a small model (Laya, 450 MB) after install and runs it on your computer. Turn it off in Settings → Brain & memory: nothing is downloaded and any copy is deleted.
- It sorts each message and reply quickly. Your brain confirms before anything changes.
- The brain dot leaves the status bar when it is off.

### Phone
- A Float button on the device tab pops the phone out as a small window over the IDE. Drag it, enlarge it, tap the screen to use the phone. It shows Agent driving while an agent is acting on it.
- Annotating a phone screen outlines the element under the pointer as you move, and a click picks it at once instead of waiting a couple of seconds.
- Annotation boxes hide while their app is not in front.

### Dialogs
- No dialog is taller than 70% of the window. A long one scrolls inside, and its title and buttons stay in view.
- Setting up a project on a workspace lists one file per row, with shorter text.

### Sharing
- Accepting a request to share your desktop no longer fails with "Starting…". It waits for the link to come up.

### Changes
- The Changes panel no longer has the "Ask an agent" bar.

### Agent card
- Each task has a Sub agent button. It asks the agent to run that task as a sub agent.

### Workspaces
- Setting up a project on a workspace no longer offers Canopy's own `.canopy` folder.

### Sharing status
- A red bar shows on every screen while your desktop is shared, with who is connected and a Stop button. The request card also has Stop sharing, and the Team panel lists who is connected.
