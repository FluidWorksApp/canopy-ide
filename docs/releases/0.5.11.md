Canopy 0.5.11 makes remote workspaces keep up when you switch around.

### Remote workspaces
- Switching tab or project no longer blanks a terminal or shows "Reconnecting…". Terminals stay connected while they are out of view.
- A terminal that does lose its connection backs off instead of retrying every second, and a reconnect shorter than three seconds no longer flips the workspace to "Reconnecting".
- The desktop reconnects as soon as you come back to the window, within five seconds at most, instead of up to a minute. If the computer slept, the desktop starts a fresh connection.
- A key held down when the connection dropped (Ctrl, Alt, Cmd, Shift) no longer stays stuck in the workspace, which is what made clicks and typing misbehave. There is a new Release keys button for the rare case it still does.
- The first keystrokes after a reconnect no longer land in the IDE as shortcuts when you were typing in the desktop.

### Previews
- A new Open in browser button on the preview opens the page in your own browser, for apps whose server only accepts its own address.
- A long agent name no longer pushes the Send screenshot button out of its panel.

### Set up from this Mac
- A new card in the workspace panel copies your projects from this Mac into a remote workspace: each repository on the same branch and commit with unpushed commits, staged and unstaged changes and new files, then reinstalls dependencies. Env and key files are sent only if you tick the option. The workspace needs updating to use it.
