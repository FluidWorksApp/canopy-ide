Canopy 0.5.23

### Fixes
- A link or file path that wraps onto the next line in a terminal is now clickable along its whole length. That covers a line the terminal wrapped and a line an agent such as Claude Code wrapped itself. A path joined across lines this way only becomes a link when the file exists. On the older xterm terminal engine, a web address an agent wrapped itself is still clickable only on its first line.
- An agent that works in another worktree of the repository now has that worktree shown in its side panel and Workspace: its branch, its changes, and Commit & raise PR. Before, they showed the checkout the agent was started in, and committing from the panel would have used that checkout.
