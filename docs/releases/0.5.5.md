Canopy 0.5.5 fixes Update workspace for running workspaces, and no longer shows a workspace as broken when an update didn't go through.

### Update workspace moves your container onto the new version
Before, **Update workspace** updated the workspace software but then always put your container back on its old version, with "Workspace container configuration differs". It now moves the container onto the new version as intended. As before, it restarts the terminals and agents in that workspace and keeps your files.

### A failed update leaves the workspace showing Running
When an update couldn't run, for example on a workspace too old to update in place, the workspace showed **Needs attention** with **Retry preparation**, even though it was running normally. It now stays **Running**, and only the update notice says what went wrong.
