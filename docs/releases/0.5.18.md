Canopy 0.5.18

### Fixes
- Workspace resources on your own machine show the computer's memory and CPU instead of "Resources unavailable".
- A busy remote workspace no longer flips the resources popover to "unavailable" when a single reading is skipped.
- Sub-agents that were lost when Claude Code restarted no longer stay "running" on the agent card; they show as failed under Previous agents.

### New
- Agents can run commands, sync a checkout and copy files between your machines (for example, build on a remote machine and install on a device plugged into this Mac), with repeatable workflows in `.canopy/machines.json`.
- The agent card has a "Waiting on you" list: questions the agent asked that are still unanswered, each answerable from the card.
- Your own canopy-host machines appear wherever cloud workspaces do: Run on, teleport, send, and agents' targets.
- All-workspaces mode joins an agent's tabs by git repository, not project name.
- Pinned tabs survive a restart.
- In a remote window, an agent's scratch files open and preview from the agent card.
