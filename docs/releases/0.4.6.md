Canopy 0.4.6 makes team chat messages selectable and copyable, makes hibernation safe when others share a workspace, and quiets workspace host logs.

### Team chat
You can select message text, including across several messages, and copy it with the usual shortcut. Select All inside a conversation selects only that conversation. Each message has a Copy button on hover, and right-clicking offers Copy for the selection or the whole message. The composer now sits on a single line at rest, with the attach and send buttons aligned to the text; it grows upward as you type more lines.

### Shared workspaces
Hibernating a workspace while other people are connected now asks first, saying how many are connected and that their sessions will stop too. A member sees Stop my session instead of Hibernate: it stops only their own session and leaves the workspace running for its owner and everyone else.

### Workspace runtime
Workspaces whose host configuration has no owner id no longer send an invalid registration to the Canopy service; they start without agent tools and say why once. Repeated service, relay and access-snapshot failures are logged once instead of on every check, and access snapshots back off while the control plane has them switched off.
