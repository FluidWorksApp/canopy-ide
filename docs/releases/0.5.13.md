Canopy 0.5.13 makes the agent card do more, and lets you start agents on a T3 Code machine.

### Agent card
- The card now sits in its own column beside the terminal instead of floating over its text. A button on the card header floats it again, and Canopy remembers your choice.
- The pull request row has one Squash & merge button with a menu, and it remembers the last method you used. Close sits on its own.
- A branch with uncommitted changes and no pull request gets Commit & raise PR: give it a title and one click commits, pushes and opens the pull request.
- The list of the agent's pull requests no longer runs past the left edge of the card.
- Servers the terminal is running get their own section with an Open button. Open shows the page in the preview, and Cmd-click opens it in your browser.
- Tasks show a progress bar of how many are done.
- Any agent can now show its task list on the card with the new canopy_tasks tool, including agents with no task tool of their own.

### T3 Code machines
- Start an agent from a machine's view: pick the CLI and Canopy opens a shell on the machine and starts it.
- Start a T3 agent thread on the machine. The thread opens in a tab with its status, messages, follow-ups and a Stop button, and threads already on the machine are listed under the project.
- Starting threads needs a new permission. Machines you paired before show "Pair this machine again to start agent threads here" until you pair them again.
- Approvals and questions from the agent are answered in T3 Code, and the thread tells you when one is waiting.

### Workspaces
- All workspaces now includes this Mac when you are in a workspace window.
- Terminals that only showed up because All workspaces was on no longer land in Resume, and rows left there from other machines are cleared.

### Devices
- The device hub fetches the phone streaming component while it installs, so the first phone stream no longer waits for a download.
- canopy_device_list no longer fails when the machine has an emulator.
