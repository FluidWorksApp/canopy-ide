Canopy 0.5.12 lets you run agents on any of your machines, and connect to a teammate's desktop.

### Agents on any machine
- Choose where an agent runs: this Mac, a remote workspace or a T3 Code machine, or let Canopy balance them. You can set it globally, per project and per agent.
- One workspace view shows this Mac, your cloud workspaces and your T3 Code machines together. T3 Code machines connect with a pairing link.
- Launching on a remote machine no longer switches your view. If the project isn't there yet, a setup step copies it, skips folders that are missing, and launches when it finishes.
- Right-clicking a component preselects it in the launch picker.
- A new Automatic account option picks the account with the most room left on its plan.
- Kiro CLI is a built-in agent. Claude, Codex, Cursor, OpenCode and any ACP provider can also run over ACP.

### Agent card
- The card shows an Assets row, including screenshots the agent took, and a Tasks row with Focus and Complete buttons.
- A failing or conflicted pull request gets a Fix it button, and hovering shows every pull request the agent raised.
- Lineage rows open to show what each sub-agent reported.
- The old agents and Pin overlay on the terminal is gone.

### Remote desktop
- Right-click a teammate and choose Connect remotely. They get a notification and an Accept button. Once they accept, you can see and control their whole desktop, over the internet through Canopy's server.

### Previews and devices
- Screenshots work while the preview isn't in front.
- Phone streaming installs itself, and the Device tab shows your phone's screen.

### Git
- Open a pull request from the Git panel with a generated title and description.

### Fixes
- Remote file drops show progress and accept any file type.
- Kiro file reads respect read permissions.

Automatic research import is removed.
