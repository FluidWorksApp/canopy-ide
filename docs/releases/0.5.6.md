Canopy 0.5.6 handles files that aren't in git yet when you bring your base branch in. It fixes two crashes, and teammates' jobs no longer go missing. The Team memory review list now tidies itself.

### Merging main with files that aren't in git yet
When the base branch adds a file that you also have locally but haven't added to git, Canopy now notices before you merge. Before, it said the merge would go through cleanly, and **Merge main in** then failed with git's own error.
- If your copy is the same as the incoming one, **Merge main in** just works. Canopy replaces your copy with the tracked one and says so first.
- If your copy is different, Canopy names the file and offers **Resolve & merge**. An agent sets your copy aside and merges. It then keeps anything only your copy had, as uncommitted changes, and removes the copy once nothing in it is lost. If it can't tell what to keep, it leaves your copy in place and tells you.

In a cloud workspace, this needs the 0.5.6 workspace software.

### Two crashes fixed
- Dismissing the "agent hooks need updating" notice in a cloud workspace no longer crashes Canopy.
- Opening **Usage** in a cloud workspace no longer crashes when it reports plan credits.

### A teammate's job no longer disappears
- A job a teammate sends you now waits in the bottom-right corner until you approve or decline it, even across a reload, a crash or a restart. Before, it could vanish and leave a "Waiting for you" notification that opened nothing. A leftover notification like that is now cleared on start.
- A job about a repository you have in a closed or hibernating project now finds that project on its own, instead of asking you to pick one.

### Team memory tidies its review list
- **Tidy up** on the **To review** tab combines proposals that say the same thing into one. It sets aside the ones that were only a single task's next step, with the reason. It also runs on its own once 12 are waiting.
- Nothing is approved for you. A combined proposal stays quarantined if any part of it was, and everything set aside stays under **All** for a month.
- The brain also proposes fewer of these in the first place.

### Quieter
- **Heads up** cards that only warned, and blocked nothing, no longer cover the agent's terminal. Blocks and approvals still show.
- **Remote access**, when Canopy links aren't live yet, now shows a short note pointing you to **On this network** instead of a "not configured" warning.
