### Cloud workspaces
The resource chip in the status bar now shows what's free in a cloud workspace and how much of it is yours, for example **You 3.4 GB · 20.8 GB free · 6.0 cores free**. Before, it counted files the system had cached as memory in use, so a workspace could look nearly full when most of its memory was free. That cache is now listed apart, as reclaimable: the system frees it automatically as soon as anything needs the room. The chip turns amber when less than 15% of the workspace's memory is free and red under 7%. It also turns amber when less than one core has been free for a while.

Click the chip to see what's available now, then who is using it: you, each teammate by name, and the workspace's own services (its desktop, browsers and Canopy). Each row shows the memory and CPU that person's terminals use. Terminals Canopy can't match to a person, such as ones started from an older Canopy, are listed as other terminals. Per-person usage needs your workspace's latest image; on an older image, the chip shows the workspace total as before.

On your own computer, the chip now also shows how much of the computer's memory is free, next to what Canopy uses.
