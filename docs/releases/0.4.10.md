Canopy 0.4.10 makes Canopy Claude Code's editor, adds instant undo for each Claude Code turn, fixes copy and paste in terminals (including remote workspaces), keeps your agent CLIs up to date, adds a reviewed Spec stage to research, and brings reactions and working notifications to team messages.

### Claude Code recognises Canopy as its editor
Claude Code now connects to Canopy the way it connects to VS Code, and `/ide` shows Canopy. When Claude wants to edit a file, the change opens as a diff you can accept, adjust or reject before anything is written. Answering in the terminal still works, and whichever answer comes first wins. What you select in the editor goes along with your next prompt automatically, and **Add to Claude** (⌘⌥K / Ctrl+Alt+K, or the editor's right-click menu) puts a reference to the file and selected lines into Claude's prompt. Claude's error checks around its edits now come from Canopy's language servers. This also works for Claude running in a cloud workspace. Turn it off in Settings → Agents → Connect Claude Code to the editor; other agent CLIs keep using Canopy's editor tools as before.

### Undo an agent turn
Each Claude Code turn in a git project is now saved as it starts and ends, so you can **Undo this turn** or go **Back to here** from the turn timeline in the agent's tab, and Redo if you change your mind. You see the changes before they are applied. When the agent is working on its own, files it changed through shell commands are covered too, not only its edits. When other agents share the same checkout, only files this agent edited are touched, so its shell-only changes there are left alone. Your branches, staged changes and commits are never touched. Database changes, network calls and deploys can't be undone, and the timeline says so. Turn it off in Settings → Agents → Snapshot each agent turn.

### Copy and paste in terminals
Copying from a terminal now works, including in cloud workspaces: the right-click menu offers Copy when text is selected, and copies made by agent CLIs inside a cloud workspace now reach your own clipboard. That includes CLIs that copy through `xclip` or `wl-copy`, such as Cursor and Aider. Terminal: copy selection and Terminal: paste are now shortcuts you can rebind.

### Agent CLIs stay up to date
Settings → Agents → Keep agent CLIs up to date automatically is on by default. Claude Code, Grok and Antigravity keep updating themselves, and Canopy updates the other installed CLIs about once a day, the same way each was installed, and never while one is running. Turned off, Canopy updates nothing and asks Claude Code, Grok and Antigravity to stop updating themselves too. Cloud workspaces keep the versions their image pins.

### Write a reviewed spec before implementing
A researched entry now has **Write spec**. One agent drafts a design document in `docs/designs/`, then separate read-only reviewers each check it against a written standard, and the drafter resolves what they find before you approve it. Implement this then follows the approved spec. Workflow steps that are meant to be read-only can now only write inside their own run folder.

### Team message notifications
Messages from teammates now show a macOS notification even while Canopy is the app in front, unless that conversation is already open on screen. Old team messages no longer come back as notifications each time Canopy starts.

### Reactions on team messages
React to any team message, in a channel or a direct message, with 👍 ❤️ 😂 🎉 👀 ✅ or any emoji, and click your reaction again to remove it. Reactions are end-to-end encrypted like messages, and they never add to an unread count or send a notification. Teammates see them once they're on 0.4.10 too. If nobody in the conversation can see your reaction yet, it's marked as not delivered. Opening or switching to a team conversation now puts the cursor in the message box.

Canopy 0.4.10 upgrades the chat history stored on your computer. After updating, an older Canopy window still open on the same computer, or going back to 0.4.9, shows "Local history could not be restored".

### Safer file links
A link to a file in a repository, for example from a teammate in chat, now only opens a file inside that repository. A crafted link could previously open a file elsewhere on your computer in the editor; such links now open as a web page instead.

### Fixes for other agent CLIs
- Antigravity's hooks are now installed where Antigravity actually reads them, so its sessions show up in Canopy.
- Grok no longer runs Canopy's Claude Code and Cursor hooks, which made its activity appear as Claude's or Cursor's.
- omp now gets Canopy's tools.
- Files changed by Codex, Grok, omp and Antigravity are now attributed to the right agent.
- Codex no longer stops trusting Canopy's hooks after an update.
- OpenCode turn starts are detected more reliably.

### Claude Code headless runs
Canopy's own Claude Code runs now always state which permission mode they use, so Claude Code 2.1.302's change to its default doesn't affect them. Agent menus mark Claude Code versions older than 2.1.302.

The cloud workspace parts of this release (Claude Code's editor connection and terminal copy) need your workspace's latest image.
