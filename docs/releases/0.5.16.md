Canopy 0.5.16 stops search indexing from hammering the disk and CPU, lets you reach your agents from your phone over Tailscale, keeps pinned tabs in view, and previews agents' screenshots in the Assets list.

### Phone access over Tailscale
- Remote access is one switch. With Tailscale running on this Mac, Settings → Remote access shows this Mac's Tailscale address with a QR code and the PIN. Open it on a phone that has Tailscale, from anywhere.
- A phone you allow under Tailscale (Settings → Remote access → Tailscale) signs in without the PIN. It can do everything a PIN sign-in can, including starting agents. Switching its Allow off signs it out within seconds.
- Canopy no longer offers phone access at this Mac's Wi-Fi address. It is over Tailscale, or over a public link (Cloudflare, ngrok or Tailscale Funnel) when you are signed out of Canopy.

### Search index
- Canopy no longer rewrites your research and notes into the search index on every pass. On one machine with 6,400 research entries this had written 137 GB to disk in about an hour and kept a core busy. The first pass after updating rebuilds research once.
- The search index's log file is capped, so it no longer makes the index look oversized and get deleted and rebuilt.
- Background indexing runs every half hour once it has caught up (it was every 5 minutes), and stops hurrying when a backlog is not getting smaller. Opening ⌘K still brings the index up to date first.
- The agents list no longer re-reads every session file on each update, which kept one or two cores busy with many agents running.

### Tabs
- Pinned tabs stay at the left of the tab strip while the other tabs scroll.

### Agent card
- Hovering an agent's screenshot or draft in Assets shows a preview even when it is outside the project, for files in an agent's scratch folders. Credential files are never previewed.

### Limitations
- Phone access over Tailscale has not been tried on a real phone yet, including whether the Tailscale name or the 100.x address is the one that loads.
- The search index changes and pinned tabs have been checked by tests, not yet in a built app.
- Canopy's own relay, for phone access from anywhere without Tailscale, is still not live.
