Canopy 0.4.1 makes managed workspaces start faster and recover on their own, keeps your agent accounts straight across profiles, and tightens up the everyday UI.

### Remote workspaces
Workspaces keep only the current image, check for disk space before an update, and say "Workspace disk is full" with the numbers instead of a generic failure. When a start fails early, Retry restarts on a fresh machine instead of asking for an administrator. Stopping shows one consistent "Stopping…" state everywhere and moves you to your local workspace instead of trying to reconnect. The Tools panel lists your agents' MCP servers in Linux workspaces too.

### Accounts and profiles
Every list of signed-in CLIs now reads the same real login state, agents always launch under the profile you picked, and the plan usage chip shows the right account and marks old numbers. The account page is now simply "Accounts".

### Everyday polish
Escape closes the top pop-up and never reaches the agent behind it. Enter sends and Shift+Enter adds a new line in team chat. The Teams panel, Shared sessions, Workspaces and the stats panel are more compact and no longer flash blank while loading. The startup screen is aligned to one column, and your balance shows straight away while it refreshes.

### Browser and resources
Save your Playwright extension token once and Chrome stops asking to approve each connection. The memory figure in the status bar now includes Canopy's own UI processes, and several places that grew memory without limit are bounded.
