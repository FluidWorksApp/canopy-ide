Canopy 0.4.3 makes shared remote workspaces feel like your own: members see named projects with their components and servers, connections stay up on slow links, and the status bar shows the account you actually selected.

### Shared workspaces
Members of a shared workspace now see your projects as named tabs, with the same components, files and Servers list you see, instead of raw folders. Agents and Git are separate switches when you share. Members no longer get "Unauthorized" when the control plane is slow to answer, or "Unexpected member runtime name" after a workspace update.

### Remote workspaces
Remote terminals stop dropping with "Workspace is busy" or "terminal attach timed out" on a slow connection. The file tree shows a spinner on the file you opened and a Loading row while a folder lists, instead of looking empty. Previewing a public site such as your production app works on a remote workspace, and the scratchpad saves notes there. Codex sessions no longer stop to ask about an incompatible background server.

### Status bar
The plan chip shows the account selected beside it, never another account's old numbers. A window with no current reading shows "--" instead of a stale percentage and its age.

### Polish
The remote desktop button uses a desktop icon, and screenshot buttons use a camera.
