Canopy 0.5.24

### Fixes
- Macs with Apple silicon get this update in place again. 0.5.23 was published without its Apple-silicon build, so those Macs were offered only the downloads page. 0.5.24 has the same changes as 0.5.23:
  - A link or file path that wraps onto the next line in a terminal is clickable along its whole length.
  - An agent that works in another worktree of the repository has that worktree shown in its side panel and Workspace: its branch, its changes, and Commit & raise PR.
- On Linux, the plus sign on buttons such as **New project** shows as a plus instead of an empty box. The buttons used a wide plus sign that many Linux machines have no font for.
