Canopy 0.5.24

### New
- Talk to a teammate's agent in your direct messages with them. Messages an agent writes are labelled with its name. Reply in that message's thread, or pick the agent in **Send to** next to the message box, and the message goes to that agent. If the agent is running on your teammate's machine, Canopy types it in as soon as the agent finishes what it is doing, and the agent's answer comes back in the same thread. Under your message you see whether it was delivered, is waiting for the agent to finish, or the agent isn't running. Your own agents can do the same with a teammate's agents. Agents stop answering each other after six messages in a row until a person writes in the thread. Teammates on an older Canopy still see the messages; they just can't send to an agent.

### Fixes
- Macs with Apple silicon get this update in place again. 0.5.23 was published without its Apple-silicon build, so those Macs were offered only the downloads page. 0.5.24 has the same changes as 0.5.23:
  - A link or file path that wraps onto the next line in a terminal is clickable along its whole length.
  - An agent that works in another worktree of the repository has that worktree shown in its side panel and Workspace: its branch, its changes, and Commit & raise PR.
