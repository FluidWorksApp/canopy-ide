Canopy 0.4.5 makes agent tabs and workspace previews more reliable, and adds file sharing, clickable links and system notifications to team chat.

### Agent tabs and muxes
Names you set stay fixed when agents report new titles, sessions reconnect or older snapshots are restored. A mux has its own saved name. Switching between local and remote workspaces preserves its panes, split ratios, focus and zoom. Agent tabs also stay in the agent rail through temporary gaps in process detection.

### Workspace previews
Previews reconnect after a workspace switch or server interruption, retain navigation and render at the display's resolution. Linux workspaces discover listening web-server ports. You can also enter a server URL directly, even when automatic detection has no result. The empty preview no longer claims project setup is running when it is only waiting for a detected port.

### Team chat and Slack
Team chat supports peer-to-peer file attachments and clickable links. Unread incoming team messages can show system notifications while Canopy is in the foreground. Slack connects through Canopy's shared app and hub, with workspace installations and companion conversations.

### Workspace runtime
The shared service runs on Linux workspaces as well as desktop installations. Runtime packaging now verifies both service binaries, and workspace release checks cover browser recovery, peer messaging and packaged host startup.
