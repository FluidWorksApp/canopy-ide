Canopy 0.5.19

### Fixes
- Checking an agent's turn no longer reinstalls a pnpm project's packages in the background, which broke its dev server and tests while the agent worked.
- On your own machines, a dev server or build that runs out of memory is slowed, then stopped on its own; the host and your agents keep running.
- Agents on your own machines come back after the host restarts, even when no Canopy window is open. Re-run `npx canopy-host up` once to turn this on.
